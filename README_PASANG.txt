# KolimNT RoboLearn - Website Anak Add-on

Isi ZIP ini adalah halaman versi anak yang lebih colorful, game-like, dan memakai maskot robot.

## File yang ditambahkan ke folder `public`
- `anak.html`
- `anak-quiz.html`
- `anak-misi.html`
- `anak-profil.html`
- `kid-style.css`
- `kid-app.js`
- `assets/kid/robot-kolimnt.png`

## Cara pasang
1. Extract ZIP ini.
2. Copy semua isi folder `public` ke folder `public` project kamu.
3. Jalankan ulang server:
   ```bash
   Ctrl + C
   npm start
   ```
4. Buka:
   ```txt
   http://localhost:3000/anak.html
   ```

## Catatan
Ini masih frontend add-on / prototype siap ditempel. Nanti bisa disambungkan ke data asli siswa, quiz asli, XP, koin, dan unlock materi dari database kamu.
